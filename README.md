# Laboration 2 - ECMAScript

## Beskrivning
Detta projekt är en interaktiv tabell som visar ramschemat för Webbutvecklingsprogrammet. Sidan är byggd med HTML, CSS och JavaScript, och använder **Fetch API** för att hämta JSON-data lokalt. 

Funktioner inkluderar:
- Sortering av kurser på kurskod, kursnamn och progression (stigande/fallande)
- Live-filtrering genom sökfält
- All uppdatering sker dynamiskt med JavaScript utan omladdning
- Byggd med Vite och publicerad via Netlify

## Tekniker
- HTML, CSS, JavaScript
- Fetch API med async/await och try/catch
- Vite som utvecklingsmiljö och byggverktyg
- Git för versionshantering
- Netlify för live-deploy
